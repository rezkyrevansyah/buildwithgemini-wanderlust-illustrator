# My agent: Wanderlust Illustrator (Travel Planner)
One-liner: A conversational agent that helps travelers design personalized itineraries with a catalog of curated destinations, activities, and illustrated travel postcards.

Tool coverage:
- Memory: Remembers traveler travel style (budget, pace, dietary needs, preferred vibes), visited locations, and saved itineraries across sessions.
- Tools: Look up destination details, fetch seasonal weather, compute day-by-day itineraries, and create customized packing recommendations.
- Catalog/UI: Destinations, attractions, local dining, and day-by-day itinerary schedules (rendered as rich A2UI cards and tables).
- Image gen: Generates vibrant, stylized visual illustrations (e.g. golden hour postcards, landmarks, scenic landscapes) for each destination in the itinerary using Gemini image generation.
- Sandbox: Computes budget allocations, currency conversions, and travel route time estimates (optional).

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for budget math, live Places/Maps API integration.
